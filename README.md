# California Housing Price Prediction

## About this Project

This is my beginner Machine Learning project where I built a Linear Regression model to predict California house prices.

In this project, I learned how to work with a real dataset, clean the data, visualize important patterns, train a machine learning model, and evaluate its performance.

---

## What I Did

- Loaded the California Housing dataset
- Performed data cleaning
- Explored the dataset using EDA
- Encoded categorical features
- Split the data into training and testing sets
- Trained a Linear Regression model
- Evaluated the model using MAE, RMSE, and R² Score
- Visualized the results using different plots

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Dataset

California Housing Prices Dataset

---

## Results

Model Performance:

- MAE: 50,670
- RMSE: 70,061
- R² Score: 0.625
